# Rieprecht GmbH – Remotion Werbevideo

Hochformat-Werbevideo (1080x1920, 30fps, 15 Sekunden) erstellt mit [Remotion](https://remotion.dev).

## Setup

```bash
npm install
```

## Vorschau (Remotion Studio)

```bash
npm start
```

## Video rendern

```bash
npm run build
```

Das gerenderte Video wird unter `out/video.mp4` gespeichert.

## Logo ersetzen

Ersetze `public/logo.png` mit dem echten Rieprecht-Logo von:
https://rieprecht-gmbh.de/images/Rieprecht-GmbH.png

## Szenen

| Szene | Dauer | Inhalt |
|-------|-------|--------|
| 1. Intro | 3s | Logo-Animation auf grünem Hintergrund |
| 2. Tagline | 2.5s | "Dein Entsorger. Dein Schüttgutlieferant." |
| 3. Produkte | 4.5s | Container, Bauschutt, Sperrmüll, Gartenabfälle |
| 4. USPs | 3s | Standort, Lieferzeit, Zuverlässigkeit, Preis |
| 5. Outro | 2s | Logo + CTA + Kontaktdaten |

## Farbschema

- Dunkelgrün: `#2d5016`
- Hellgrün: `#3a6b1a`
- Creme: `#f5f0e8`
- Braun: `#1a0a00`
